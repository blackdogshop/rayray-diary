# 離乳期餵食紀錄優化 — 需求規格

> 目標：把 App 從「餵奶紀錄」升級為「離乳期營養追蹤」。
> 支援混合餐、熱量換算、每日攝取目標進度、離乳比例、體重趨勢提醒，並讓食物設定可維護，之後換品牌 / 轉全罐頭都不用改程式。

⚠️ **健康免責**：熱量目標與體重提醒僅為估算參考，非獸醫建議。實際餵食量與增重評估請以獸醫為準。App 內所有熱量目標一律以「建議範圍」呈現並標註此提醒。

---

## 1. 核心資料結構（每筆餵食）

沿用現有欄位，新增以下欄位（這是最關鍵、之後轉全罐頭也不用大改的骨架）：

| 欄位 | 說明 |
|---|---|
| `can_g` | 罐頭克數 (g) |
| `formula_scoop` | 奶粉湯匙數 |
| `water_ml` | 額外加水 (mL)，只計水分、不計熱量 |
| `kcal` | 本餐總熱量（自動計算後存下來） |
| `appetite` | 食慾：`all`吃光 / `half`吃一半 / `few`吃幾口 / `none`不吃 |
| `food_temp` | 食物溫度：`cold`冷 / `room`常溫 / `warm`微溫 |
| `food_id`（選填） | 這餐罐頭用哪個食物設定換算的 |

保留現有：`t 時間`、`g 體重`、`pee`、`poop`、`note`、`who`、`med/topical/wound/vaccine`、`ml 奶量`（見待確認 #4）。

---

## 2. 換算規則

- **奶粉**：1 湯匙 = **12.4 kcal**；建議沖泡比例 1 湯匙 : **30 cc** 水（僅參考提示）。
- **拌罐頭時**：允許只加 10cc、15cc… 等不同水量，不強制 30cc。
- **罐頭**：`罐頭 kcal = can_g × kcal_per_g`；`kcal_per_g` 由「食物設定」提供。
- **本餐總熱量**：`罐頭 kcal + 奶粉 kcal`。
- **額外加水**：只計入「水分」，**不計入熱量**。

---

## 3. 首頁彙總

- **今日總熱量 (kcal)**
- **今日攝取目標進度**（對照建議範圍的百分比 / 進度條）
- **今日摘要**新增：罐頭總 g、奶粉總湯匙、額外加水總 mL、總 kcal
- **離乳比例**：當日熱量中，罐頭佔 %、奶粉佔 %
- 卡片調整：原「今日奶量」→「**今日攝取**」（顯示總 kcal + 目標進度）
- 自動顯示「**距離上一餐多久**」

---

## 4. 每日熱量目標（依體重估算）

- 依「最新體重」自動估算，**顯示建議範圍**而非單一死數字。
- 參考公式（可於設定調整倍率）：
  - 靜止能量需求 `RER = 70 × (體重kg)^0.75`
  - 幼貓成長期 `每日建議 ME ≈ 2–3 × RER`（越小倍率越高）
  - → 顯示為區間，例如 `RER×2.0 ~ RER×3.0`
- 明確標註「估算，請以獸醫建議為準」。
- 亦允許直接輸入獸醫給的目標值（見待確認 #2）。

---

## 5. 圖表

- **每日奶量圖 + 每日罐罐圖 → 整合為「每日營養攝取圖」**
  - 堆疊長條：罐頭 kcal 與 奶粉 kcal 用不同顏色
  - 柱頂顯示當日**總 kcal**
- **切換「原始攝取量」**：改看罐頭 g、奶粉湯匙數、水 mL
- **體重**：7 日平均增重 + 成長趨勢；連續數日不增或下降 → 顯示提醒（同樣標註以獸醫為準）

---

## 6. 新增 / 編輯表單

- 混合餐輸入：罐頭 g、奶粉湯匙、加水 mL（同一筆可一起填）
- 沖泡比例提示：填奶粉湯匙時提示「建議 N 匙 ≈ N×30 cc 水」
- 食慾：吃光 / 吃一半 / 吃幾口 / 不吃
- 食物溫度：冷 / 常溫 / 微溫

---

## 7. 食物設定頁（多品牌可維護）

- 每個食物項目：名稱、類型（罐頭 / 奶粉）、`kcal/g` 或 `kcal/湯匙`、建議沖泡比例
- 儲存在 Firestore（例如 `foods` collection），換品牌不用改程式
- 預設項目：
  - 皇家離乳罐：`kcal/g` = 待填（見待確認 #1）
  - 奶粉：12.4 kcal/湯匙、建議 1 匙 : 30 cc

---

## 待確認事項（建議實作前先定案）

1. **皇家離乳罐 kcal/g**：請看罐身「代謝能 / ME」標示（通常標 kcal/100g 或每罐 kcal）。乾糧版約 403 kcal/100g，但你的是罐頭 / 慕斯，數值低很多。給我數字或罐身照片即可設定。
2. **熱量目標**：用上述幼貓公式自動估「範圍」可以嗎（會標明估算）？還是你想直接輸入獸醫給的目標值？或兩者都要。
3. **奶粉**：12.4 kcal/湯匙、1 匙:30cc 是你手上這罐嗎？品牌 / 名稱？
4. **舊「奶量 mL」欄位**：離乳過渡期還在瓶餵 → 保留；還是要逐步淘汰？
5. **沖泡的水**：要不要一起算進「今日水分」，還是只計「額外加水」？

---

## 建議分階段實作

- **階段一（核心資料 + 換算）**：混合餐輸入（罐頭g / 奶粉匙 / 加水mL）、本餐 kcal、食慾、溫度、距上一餐；每筆存 `can_g / formula_scoop / water_ml / kcal / appetite / food_temp`。→ 先開始收集資料，之後圖表才有東西畫。
- **階段二（首頁彙總）**：今日攝取卡、今日總熱量、目標進度、離乳比例、摘要擴充。
- **階段三（圖表整合）**：每日營養攝取堆疊圖 + 原始攝取量切換；7 日平均增重、體重提醒。
- **階段四（食物設定頁）**：多品牌管理，換品牌不改程式。
